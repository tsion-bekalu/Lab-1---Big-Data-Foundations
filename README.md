## Overview

This project explores basic Big Data concepts using Python and Pandas. It uses a loan applications dataset to perform data exploration, statistical analysis, data quality checks, and default probability analysis.

## Dataset

The project uses `loan_applications.csv`, which contains 305 loan application records and 8 columns.

The dataset includes:
- Applicant ID
- Monthly income
- Loan amount
- Employment type
- Collateral status
- Application channel
- Credit history
- Default status

## Tasks Covered

1. **Dataset Exploration:** Inspect the dataset's shape, data types, and sample records.
2. **Descriptive Statistics:** Calculate the mean, median, standard deviation, and mode.
3. **Data Quality Audit:** Identify missing values and duplicate records.
4. **The Five Vs of Big Data:** Explore Volume, Velocity, Variety, Veracity, and Value.
5. **Default Probability Analysis:** Calculate the overall default probability and compare default rates for applicants with and without collateral.
